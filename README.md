# Rock-Paper-Scissors Game 🎮

A console-based Rock-Paper-Scissors game written in C++ as part of my ProgrammingAdvices — Course 05: Algorithms & Problem-Solving Level 2 learning journey.

## Features

- Player input validation
- Random computer choices
- 3 rounds per game
- Rock, Paper, and Scissors rules
- Round-by-round results
- Final score
- Player / Computer / Draw result
- Replay option
- Windows console screen handling

## Concepts Practiced

- Enums
- Functions
- Loops
- Conditional statements
- Random number generation
- References
- Input validation
- Global variables
- Game-state organization
- Problem solving

## Run

Open the project in Visual Studio as a C++ Console project, build it, and run it.

Choose:
- 1 = Rock
- 2 = Paper
- 3 = Scissors

The program uses Windows console commands such as cls and color.
